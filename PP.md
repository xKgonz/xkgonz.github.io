# Privacy Policy

Last Updated: [June 18, 2025]

NotKgPortfolioBot ("the Bot") values your privacy. This document outlines what data is and is not collected.

## 1. Data Collection
The Bot does **not** store any personal data from users. All commands are processed in real-time and are not logged or retained.

## 2. Server Information
Some temporary data such as server ID, channel ID, and user ID may be used **transiently** to deliver command functionality. This data is not stored or shared.

## 3. Third-Party Services
This Bot does not share any data with third-party services.

## 4. Security
The Bot runs on secure hosting and does not expose any private information. However, users should avoid submitting sensitive data through public commands.

## 5. Contact
If you have any concerns, you may contact the developer at 'xkg_1' via Discord.
